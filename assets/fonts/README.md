# Geist local assets

Unmodified static TTF files obtained from the Google Fonts CSS endpoint for Geist weights 400, 500 and 700 on 2026-11-22.
The copyright and license URL are confirmed in the downloaded fonts' name table (IDs 0 and 14). OFL.txt includes that copyright statement and the standard SIL OFL 1.1 text.

- geist-regular.ttf: weight 400
- geist-medium.ttf: weight 500, also used for the interface's 600 weight
- geist-bold.ttf: weight 700

Chinese characters use the device's PingFang SC or Microsoft YaHei. All font files are served locally; no runtime font CDN request is required.
