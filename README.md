# 新云 · AI 提案工作台

INTERCITY HACK 湖州场 / AI + 办公赛道 / 上海新云传媒命题。

本地运行的户外媒体提案原型：客户需求 → 品牌依据与门店圈选 → 档期库存筛选 → 预算配单 → 可离线交互的 HTML 提案。

## 运行

需要 Node.js 20 或以上，无 npm 依赖，无构建步骤。

    npm start

或直接运行 `node server.mjs`。浏览器打开 http://localhost:3000 。服务仅监听本机 127.0.0.1。

测试：`npm test`。测试覆盖原表逐行核对、空值保留、文件改名哈希、导入导出、报价约束、列表分页、材料检索与 HTTP 接口。浏览器交互回归：启动服务后运行 `node tests/browser-real.mjs` 和 `node tests/browser-pagination.mjs`（需要 Playwright 与 Edge / Chromium）。

## 功能

1. 五个指定行业，100–500 万预算滑杆与 100 / 200 / 500 万快捷切换。
2. 公交、地铁或组合；2027 年内排期；包含制作费的含税预算约束。
3. 规则配单：行业场景、地标邻近、媒体等级、区域多样性与递减收益。确定性启发式，不承诺全局最优。
4. 库存 CSV / XLSX 导入，字段识别、预览、错误阻断、多工作表选择；价格表按编号或唯一等级匹配。
5. 资源详情展示报价公式、价格来源、库存查询日期、可售期、推荐理由及排除原因。
6. 门店 / 地标经纬度与半径管理、品牌研究证据登记。
7. 交互式 HTML 导出：单文件、无联网依赖、现场切换预算并重算明细与总价。
8. 真正的 XLSX 导出（投放清单、报价口径、品牌与地标依据、排除记录）及防公式注入的 CSV。
9. 草稿本地保存、项目 JSON 备份与恢复、打印 / PDF、移动端布局、路演模式。
10. 可选真实模型接口：只生成策略草稿，永不参与库存或金额计算。
11. 库存与推荐清单支持收起 / 展开、首页 / 末页及前后翻页；工作台默认每页 5 条，资源库与提案默认每页 10 条，可切换 5 / 10 / 20 条。搜索与类型筛选作用于完整清单，导出不受当前页影响。
12. 各页面顶部提供相关材料搜索，检索已导入库存、历史人流报告、来源文件名及调研摘要。支持类型筛选、每页 6 条结果和详情查看；输入为空时自动收起结果，不检索未导入文档或外部网络。

## 导入数据

### 导入客户需求（自动填入，整体确认）

工作台「客户投放需求 → 导入客户需求」支持粘贴客户邮件 / brief，或上传 TXT、CSV、XLSX。可下载空白 CSV 模板，用 Excel 填写后导入。模板没有预填客户或金额。

1. 粘贴原文或选择文件。TXT / CSV 上限 1MB，XLSX 上限 10MB；单份需求最多 50,000 字符。旧版 XLS 请另存为 XLSX，Word / PDF 请先复制文字。
2. 表格支持「字段 / 填写内容」纵向模板或表头加客户行的横向表格。单份有效文件自动提取并填入左侧「客户投放需求」；Excel 可选工作表，多客户文件只需选择客户。
3. 本地规则提取品牌、行业、预算、媒体、投放日期、目标、人群、区域、门店要求和备注。保留原文依据；单位不明、金额范围、重复冲突和不完整日期不自动选值。不是外部 AI 模型解析。
4. 识别结果直接填写到现有行业、品牌、预算、媒体、日期和目标控件，标注「待整体确认」，没有逐项勾选弹窗。可直接修改；补充信息在同一表单的折叠区中编辑。缺失或无效字段保留原值并提示。
5. 最后点击一次「确认需求并生成方案」。系统检查必填内容后记录整体确认，再按现有库存计算推荐。待确认草稿可刷新恢复、查看原文或撤销回到导入前；确认前不生成可导出的正式提案。现有库存缺少价格等报价条件时仍不会生成报价。

预算以「万元」为单位，范围 100–500；日期须在 2027 年内。导入不调整库存或刊例价格，也不替客户锁定资源。待确认草稿与确认记录保存在当前浏览器并随项目 JSON 备份；原文不传给外部模型，XLSX 仅交由本应用现有接口解析。

交互回归：启动服务后运行 `node tests/browser-brief-import.mjs`。

当前源文件已生成 data/real-data.mjs，启动服务即可加载，无需在浏览器重复导入。后续可在界面导入更新的 CSV / XLSX；原始红豆 resourceType、线路、运营公司、线路等级、媒体类型、空位数表头均可识别。

库存最低识别字段：`媒体名称 / 线路名称`、`媒体类型`、`空车数 / 可售数量`。

进入报价还必须具备以下条件：

| 字段 | 口径 |
| --- | --- |
| 媒体编号 | 建议用红豆稳定资源 ID，不能重复 |
| 媒体类型 | 公交车身 / 地铁出入口；支持 bus / metro |
| 可售开始、可售结束 | YYYY-MM-DD，完整覆盖提案档期 |
| 28天刊例价 | 单资源人民币含税金额；须明确值，不能用区间或猜测均价 |
| 计价天数 | 必须明确为 28；其他口径人工核实，不自动换算 |
| 制作费 | 单资源一次性含税金额；确认无费用填 0，空白为待核验 |
| 含税 | 是 / true / 1；未知口径不报价 |
| 查询日期、来源、价格来源 | 保留导出时间与刊例材料出处 |
| 纬度、经度 | 可选，WGS84；公交是参考点，不代表整线轨迹 |
| 场景标签 | 可选，顿号分隔，如 商圈、办公、社区；应有依据 |
| 人流量、人流月份 | 可选，仅接受 2023-01 至 2023-12；不推算 2027 曝光 |

价格表优先按明确媒体编号匹配；不带编号时才按媒体类型与等级唯一匹配。多个候选时不选择最便宜价格、不覆盖原价。形式复杂时请使用媒体编号匹配。

支持 UTF-8 / 常见 GB18030 CSV、一般 XLSX（共享字符串、内联字符串、数字、日期样式、缓存公式值）；不支持旧版 XLS、加密表、宏执行、复杂合并表头。公式无缓存时需在 Excel 计算并保存。限制：单文件 10MB、5000 行，ZIP 有解压大小限制。

## 报价模型

    投放天数 = 结束日 - 开始日 + 1
    计费周期 = ceil(投放天数 / 28)
    单资源金额 = round(28天刊例价 × 计费周期 × 销售价格系数, 2) + 制作费
    行金额 = 单资源金额 × 推荐数量

价格系数默认 1.00，只作用于媒介费；实际折扣由销售按培训口径输入。合计不超过预算；库存不足保留预算余量，不补造资源。行业评分是规则分，不是效果预测。

## 可选 AI 策略

复制 `.env.example` 为 `.env`，填写兼容 Chat Completions 协议的服务：

    AI_BASE_URL=https://你的模型服务地址/v1
    AI_API_KEY=你的密钥
    AI_MODEL=服务支持的模型名

服务端请求 `AI_BASE_URL + /chat/completions`。支持 HTTPS 和本机模型。密钥不发给浏览器，不写入备份，不导出到提案。未配置时明确提示，规则配单和导出照常运行。

「覆盖分析 → 生成 AI 策略草稿」先展示发送范围，再由用户触发。只发送行业、品牌名称、预算、目标和用户填写的调研摘要，不发送原始库存、价格明细、账号或资料包。策略以纯文本展示，人工核实后使用。本次未提供凭据，真实模型服务尚未完成端到端验证。

## 界面与交互

界面采用 Taste Code 的 Framed Sheet 浅色工作台方向：统一左侧导航、顶部材料检索、白色工作区和状态行。需求、覆盖依据、媒体库存、报价条件分别显示当前准备状态，可点击进入对应页面。

- 客户需求导入后直接填入原表单，可修改，再一次整体确认；没有逐字段确认步骤。
- 工作台优先展示库存清单；没有坐标时，用简短入口提示替代大面积空地图。
- 清单保留分页、收起和全量导出。历史报告与来源文件支持折叠和局部滚动。
- 顶部搜索支持库存、报告、文件和调研材料；Esc 收起结果，Enter 重新打开。
- 平板使用双列表单；手机使用底部导航，长表格在区域内滚动。

应用运行后执行以下检查，覆盖五个页面在 1440 / 768 / 390 像素的布局、最小字号、导航、检索弹层和目录折叠。截图保存在 .taste-skill/after/。

    node tests/browser-ui.mjs

## 更新 data 目录后的处理

生成的数据模块已随项目提供，Node.js 运行不依赖 Python。更新原始 Excel 后再执行以下离线准备步骤：

    python -m pip install -r scripts/requirements.txt
    python scripts/build-data.py

脚本只读取源文件。需要按表内线路整理新文件名称时，另行运行 scripts/align-source-names.py；该脚本校验路径、避免覆盖重名文件并记录内容哈希。

生成模块的版本随源文件改变；页面刷新时会更新文件库存。原始 XLS / XLSX 不通过 Web 静态地址公开提供。

## 服务器运行

这是 **Node.js 项目**，服务器面板选择「Node项目」。入口 server.mjs，启动命令 npm start，默认端口 3000。项目无 npm 运行依赖，不需要构建前端。

上传完整应用代码、lib 目录及 data/real-data.mjs。原始 Excel 和 Python 工具只有重新生成数据时需要。默认监听 127.0.0.1，通过服务器反向代理访问；公网部署仍需账号权限与访问控制。

## 文件结构

- `index.html` / `styles.css` / `app.js`：响应式工作台，无框架依赖。
- `lib/engine.mjs`：报价、预算分配、CSV、字段映射和校验。
- `lib/xlsx.mjs`：受限 XLSX 读取及真实 XLSX 生成。
- `lib/export.mjs`：独立 HTML 与报价工作表。
- `data/real-data.mjs`：由用户源文件生成的库存、历史画像和来源清单。
- `scripts/build-data.py`：只读解析原始 XLSX / XLS 并生成前端数据。
- `server.mjs`：静态服务、Excel API、可选 AI 代理。
- `tests/`：约束、文件、注入防护、离线提案、HTTP 测试。
- `ONE_PAGER.md`：提交用一页纸，团队姓名待填写。
